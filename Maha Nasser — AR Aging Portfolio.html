How It Was Built

Methodology

01
Data Preparation
Cleaned and structured 900+ invoice records in Excel. Added Amount Paid and Paid Percentage columns based on payment status logic.
02
Data Modeling
Built a Customer Information master table and established a Many-to-One relationship with the main AR table in Power BI.
03
DAX Calculations
Created calculated columns for currency conversion (5 currencies → QAR), Days Overdue, Aging Bucket, and Risk Level using SWITCH and DATEDIFF.
04
Measures & KPIs
Built 6 core Measures including Total Sales, Total AR, Total Outstanding, Overdue Amount, Collection Rate, and Average Days Overdue.
05
Dashboard Design
Designed 2-page interactive dashboard with KPI Cards, Aging Analysis bar chart, customer table, trend analysis, and collection donut chart.
06
Insights & Analysis
Identified critical collection risk: 80% of overdue balance concentrated in +181 Days bucket, with average overdue period of 416 days.
Note: All data in this project is simulated for portfolio demonstration purposes. The methodology, DAX formulas, and analytical approach reflect real-world accounting practices. Full Power BI file and Excel dataset available upon request.
